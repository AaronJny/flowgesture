# 行云手势

[English](README.md) | [简体中文](README.zh-CN.md)

原生 macOS 菜单栏工具，让鼠标手势、滚轮、触控手势与日常自动化操作更顺手。

**开发预览版：**目前已能构建并启动，真实设备验收仍在进行。这是独立编写的项目，不是修改版 BAB；无需账号、订阅，没有强制更新和遥测。

## 功能

- 按住鼠标按键绘制手势，显示轨迹；未匹配的点击会回放给原应用。
- 映射鼠标侧键和键盘快捷键，通过屏幕边角触发操作。
- 独立反转鼠标滚动方向、调整速度、平滑普通滚轮输入。默认依据设备身份保留触控板原有方向，无法识别的输入不作修改。
- 从支持的触控设备中识别多指轻点、滑动和捏合，涵盖触控板与触控鼠标。
- 设置全局或按应用生效的规则、修饰键、优先级和排除应用。
- 执行快捷键与 AppleScript，打开网址、文件和应用，选择菜单项，排列窗口，执行媒体与系统操作。
- 使用中文或英文界面编辑规则，导入导出 JSON、恢复备份，并通过自选文件夹同步。

触控设备兼容性及与 macOS 原生手势的冲突仍需实机验证。目前尚未实现 BAB 的全部手势与动作，剩余范围见[验收清单](docs/ACCEPTANCE.md)。

## 安装与使用

需要 **macOS 13 或更新版本**。开发构建同时包含 Apple Silicon 与 Intel 可执行文件。

1. 打开一次成功的 [GitHub Actions 构建](https://github.com/AaronJny/flowgesture/actions)，下载 `FlowGesture-macos` 产物，解压其中的 ZIP 文件。
2. 将 `FlowGesture.app` 移到“应用程序”并打开。开发版使用临时签名，尚未公证；macOS 可能要求在“隐私与安全性”中确认打开。
3. 从菜单栏打开“行云手势设置”。前往“系统设置 → 隐私与安全性”，授予“辅助功能”和“输入监控”权限，然后刷新权限或重新打开应用。
4. 点击“添加示例”或“添加规则”，选择触发方式及动作，再启用行云手势。触控示例默认关闭，便于你先决定它与系统手势如何配合。

AppleScript 控制其他应用时，可能另行请求“自动化”权限。随时可从菜单栏暂停监听；应用没有强制更新机制。

## 配置与同步

规则保存在 `~/Library/Application Support/FlowGesture/rules.json`。导入导出使用 JSON；替换配置前会保留上一版本备份。导入或同步到来的规则先暂停，供检查后再执行。

如需同步，在设置中选择 iCloud Drive 或其他同步文件夹。行云手势仅在运行期间检查该文件夹，发现编辑冲突会让你选择保留哪个版本。退出后不会继续运行，不会创建云端账号，也不会静默覆盖冲突。

## 从源码构建

在 macOS 安装 Xcode 命令行工具及 Swift 5.9 或更新版本：

```sh
swift test
bash scripts/test-native-bridge.sh
bash scripts/build-app.sh
open build/FlowGesture.app
```

构建脚本生成通用应用和 `build/FlowGesture-macos.zip`。

## 项目结构

- `FlowGestureCore`：规则模型、校验、匹配与确定性的手势识别。
- `FlowGestureNative`：可选的系统触控采集与设备身份识别，不可用时明确报告。
- `FlowGestureApp`：SwiftUI 设置、事件处理、生命周期和排队执行的动作。

未捆绑第三方实现代码或二进制文件。项目公开前将选择分发许可证。实现与硬件验证细节见[触控及设备说明](docs/touch-device-validation.md)。
