# 行云手势

[English](README.md) | [简体中文](README.zh-CN.md)

让鼠标和触控板，按你的习惯工作。

行云手势是一款原生 macOS 工具，将自定义手势、顺滑滚动和日常快捷操作放在一起。规则保存在你的 Mac 上，只有选择同步文件夹后才会同步。

## 你可以做什么

- **把操作画出来。** 使用方向手势，或录制自己的自由形状，鼠标轨迹清晰可见。
- **用好每一个按键。** 为鼠标侧键、单击／双击／三击和键盘快捷键分配操作。
- **按习惯滚动。** 平滑鼠标滚轮、调整速度，并独立反转方向，不改变触控板设置。
- **自定义触控手势。** 映射多指轻点、滑动和捏合，为触控板与触控鼠标分别设置规则。
- **适配不同应用。** 使用全局或应用专属规则，搭配修饰键和屏幕边角触发操作。
- **选择想做的事。** 执行快捷键或 AppleScript，打开应用、文件和网址，选择菜单命令，排列窗口，控制媒体播放。
- **留住你的配置。** 导入导出规则、恢复备份，或通过自选文件夹同步；设置中可切换中文与英文界面。

## 开始使用

1. 下载并解压，将 `FlowGesture.app` 移到“应用程序”。
2. 打开应用，从菜单栏进入“行云手势设置”。
3. 在“系统设置 → 隐私与安全性”中授予“辅助功能”和“输入监控”权限，然后刷新权限状态。
4. 点击“添加示例”体验配置，或点击“添加规则”创建自己的操作；准备好后启用行云手势。

随时可以从菜单栏暂停或退出。AppleScript 控制其他应用时，可能还需要授予“自动化”权限。
